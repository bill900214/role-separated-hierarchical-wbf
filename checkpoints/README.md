# Checkpoint Availability

Checkpoint binaries are not included.

- YOLOR-D6, YOLOv10-X, and YOLOv13-L use public UT-T1 checkpoints and are
  used for inference only in this study.
- D-FINE-L and DEIMv2-S were fine-tuned for the Transformer auxiliary branch.
- The DEIMv2-S-960 checkpoint is not distributed; its actual prediction JSON
  used by the final fusion is included.

Obtain checkpoint files from their original providers and follow the
corresponding redistribution terms.
