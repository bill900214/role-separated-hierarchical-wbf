# Checkpoint Availability

Checkpoint binaries are not included in this repository.

- YOLOR-D6, YOLOv10-X, and YOLOv13-L use public UT-T1 checkpoints.
- D-FINE-L-1536 and DEIMv2-S-832 were fine-tuned for this study.
- The DEIMv2-S-960 checkpoint was not retained; its actual prediction JSON
  used in the final fusion is included.

Obtain upstream and public checkpoint files from their original providers
and review their redistribution terms before use.
