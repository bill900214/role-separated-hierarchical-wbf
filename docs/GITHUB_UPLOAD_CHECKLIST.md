# GitHub Upload Checklist

Before making the repository public:

- [ ] Remove absolute server paths.
- [ ] Remove credentials, tokens, private keys, and `.env` files.
- [ ] Add exact upstream repository URLs and commit hashes.
- [ ] Add original shell commands or cleaned wrappers for all reported stages.
- [ ] Verify the DEIMv2-S-960 checkpoint and checksum.
- [ ] Verify every JSON filename against the paper.
- [ ] Add checkpoint download links or a GitHub Release.
- [ ] Add qualitative figures generated from true JSON only.
- [ ] Review third-party licenses.
- [ ] Replace `REPLACE_WITH_PUBLIC_GITHUB_URL` in `CITATION.cff`.
- [ ] Keep the repository private until the audit is complete.
