# DEIMv2 Inference

`infer_deimv2_832.py` is an experiment-specific wrapper for the DEIMv2-S-832
branch and requires an upstream DEIMv2 checkout and checkpoint.

The DEIMv2-S-960 checkpoint is not distributed. Its actual prediction JSON
used by Level III is available at
`predictions/transformer_inputs/submission_deimv2_960_conf052_iou045.json`.
